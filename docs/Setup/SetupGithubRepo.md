# SETUP GITHUB REPOSITORY

### 1. Initial git repository
```bash

git init

```

### 2. Add all file to commit
```bash

git add .

```

### 3. Commit with message
```bash

git commit -m "Commit message"

```

### 4. Set branch to main
```bash

git branch -M main

```

### 5. Add path url to repository
```bash

git remote add origin https://github.com/repopath/reponame.git

```

### 6. Push file to main repository
```bash

git push -u origin main

```

### 7. Create new dev branch
```bash

git checkout -b dev

```

### 8. Push new dev branch
```bash

git push -u origin dev

```
